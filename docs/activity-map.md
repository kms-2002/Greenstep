# 실천 지도

## 2026-10-21: 진주시 행정구역 지도

현재 화면은 `JinjuRegionMap`과 `jinjuRegions.json`을 사용합니다. 아래의 1km 격자 설명은 이전 버전 기록입니다.

- 경계: SGIS 기반 vuski/admdongkor의 2026-10-01 GeoJSON. 진주시 30개 읍면동만 추출했습니다.
- 14개 행정동 유지, 16개 읍면은 서부(수곡·대평·명석), 북부(집현·미천·대곡), 동부(지수·사봉·일반성·이반성), 금산·진성, 남부(내동·정촌·문산·금곡) 5개 앱 권역으로 통합했습니다. 도형 합집합으로 인접성을 확인했습니다.
- `scripts/prepare_jinju_regions.py`로 재생성할 수 있습니다. 원본 다운로드를 `boundaries-source.local`에 두고 Shapely가 설치된 Python에서 실행합니다.
- 출처·라이선스는 `docs/boundary-data-license.txt` 및 화면 하단에 표시합니다. 경계 도형을 단순화했으므로 측량용이 아닙니다.
- `202610210002_region_map.sql`이 지역 카탈로그, 참여 기록의 `map_region`, 인증 완료 함수 `gs_complete_in_region`, 집계 함수 `gs_region_map`을 추가합니다.
- 장소를 선택한 인증은 승인된 사진·포인트·지역을 같은 트랜잭션으로 처리합니다. 재요청은 최초 완료 결과를 반환합니다.
- GPS는 브라우저 안에서만 행정구역을 찾습니다. 서버에는 좌표 대신 지역 ID를 전달합니다.
- 이전 1km 좌표는 경계 오분류 가능성이 있어 자동 변환하지 않습니다. 지역 미등록으로 표시합니다.
- 활동 비중, 직전 동일 일수 대비 인증 건수, 추천 챌린지 및 데이터 상태가 연결됩니다. 1인당 지표는 제외했습니다. 현재 기간은 오늘의 진행분을 포함하므로 이전의 완결된 기간과 시간량이 완전히 같지 않습니다.
- 공식 기준은 진주시 탄소중립지원센터 기본계획의 관리권한 범위(2018 총배출량 2,125.7천tCO₂eq, 2030 목표배출량 1,266.9천tCO₂eq)입니다. 현재 실시간 배출량이 아니고 읍면동별로 나눠 넣지 않습니다.
- 50kg 체험 목표를 제거했습니다. 한국기후·환경네트워크의 ‘온실가스 1인 1톤 줄이기’ 캠페인을 참고하여 개인 실천 참고 목표를 1,000kg으로 표시합니다. 최근 365일(한국 날짜 기준 오늘 포함)의 모든 지역·지역 미등록 인증 중 계산 근거가 있는 감축 추정량을 합산합니다. 365일은 앱 운영 기준이며 공식 개인 의무량이나 캠페인 공식 기한이 아닙니다.
- 국가 목표는 2018년 순배출량 742.3백만 tCO₂eq 대비 2035년 53~61% 감축으로 별도 표시합니다. 국가 목표를 인구나 행정동 수로 나누지 않습니다. 지역 상세에는 해당 지역의 선택 기간 감축 추정량만 표시하며, 지역별 목표 잔여량은 표시하지 않습니다.
- 참고 출처: https://www.kcen.kr/cbook/index.green / https://www.mcee.go.kr/home/web/board/read.do?boardId=1818900&boardMasterId=939&menuId=10598 (확인일 2026-10-21). 설정은 `src/data/carbonTargets.ts`, 개인 집계는 `src/components/mobile/CarbonGoal.tsx`에 있습니다. 현재 앱의 잔반 무게 기반 추정만으로 캠페인의 생활 전반 감축 실적을 대표하지 않습니다.
- 확인된 장소는 판문동 진양호공원 1곳입니다. 그 외에는 지역명을 이용한 외부 지도 검색을 제공하며 제휴·보상 가능 여부는 보증하지 않습니다.
- Supabase 마이그레이션은 적용되었습니다. 프론트엔드는 GitHub main 반영 후 기존 Vercel 연결을 통해 배포됩니다.

## 이전 버전: 1km 격자

랭킹 탭과 홈의 랭킹 바로가기를 실천 지도로 교체했습니다.

## 데이터 흐름

1. 로그인한 사용자가 사진 인증 화면에서 실천 장소를 선택합니다.
2. 선택 위치는 브라우저에서 소수점 둘째 자리로 반올림합니다. 원래의 정밀 좌표는 서버에 전송하지 않습니다.
3. 기존 Groq 사진 승인 이후 `gs_complete_at_location`이 기존 인증·포인트 지급 함수를 호출하고 위치를 같은 DB 트랜잭션에서 저장합니다.
4. 위치를 선택하지 않으면 기존 `gs_complete` 경로로 정상 인증합니다.
5. `gs_activity_map`은 한국 날짜 기준 최근 7일/30일/365일의 완료 기록만 집계합니다.

## 적용

Supabase SQL Editor에서 `supabase/migrations/202610210001_activity_map.sql`을 적용합니다.
기존 계정·참여·사진 인증 마이그레이션이 선행되어야 합니다.
프론트엔드는 `npm install` 및 `npm run build` 후 기존 배포 경로로 배포할 수 있습니다.
지도 API 키는 필요하지 않습니다.

## 집계와 한계

- 기본은 본인의 기록입니다. 함께한 실천은 활동 공개 설정이 켜진 회원의 기록만 포함합니다.
- 공동 지도에서 한 좌표 셀에 참여한 회원이 3명 미만이면 해당 셀을 표시하지 않습니다. 회원 ID·닉네임·원본 사진은 지도 RPC에서 반환하지 않습니다.
- 기존 기록의 위치를 추정하거나 학교·주소로 채우지 않습니다. 위치 없는 기록은 미등록 건수로만 집계합니다.
- 약 1km 격자는 행정동 경계가 아닙니다. 지도 범위는 화면 및 입력 범위이고 진주시 행정경계 판정이 아닙니다. 동별 비교를 하려면 공식 경계 데이터와 좌표-행정동 매핑을 추가해야 합니다.
- 위치는 사용자가 선택한 값이며 GPS 증명이나 AI 검증 결과가 아닙니다.
- CO₂ 합계에는 기존 계산 결과의 상태가 `estimated`인 기록만 포함합니다. 포인트는 감축량으로 환산하지 않습니다.
- 기존 창원시 자료 기반 잔반 계산의 한계는 그대로 적용됩니다. 진주시 공인 감축 실적이나 도시 전체 배출량이 아닙니다.
- 지도 배경은 OpenStreetMap, 지도 렌더링은 Leaflet입니다. 출처 표기를 유지해야 합니다. 대규모 운영 시 타일 제공 정책에 맞는 제공자를 선정해야 합니다.

참고: https://leafletjs.com/reference.html / https://operations.osmfoundation.org/policies/tiles/
