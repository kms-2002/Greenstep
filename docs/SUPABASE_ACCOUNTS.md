# 실제 계정·활동·친구 저장

## 현재 배포 상태 (2026-10-17)

Supabase 프로젝트 `dfgdtvgpnsyjhnsttibs`의 SQL Editor에서 아래 DB migration 001→002→003을 적용했습니다. public 테이블 11개 모두 RLS 활성화, 챌린지 23개, 탄소 기준 82개, 앱 함수 12개, 비공개 인증 사진 버킷 1개를 조회로 확인했습니다. 기존 Auth 계정 중 프로필 누락은 0개입니다. **002를 다시 실행하지 마세요.** 변경된 Edge Function 배포는 아직 완료되지 않았습니다. 실제 계정 두 개를 이용한 회원가입·친구 추가 동작은 아직 검증하지 않았습니다.

## 구성

- Supabase Auth: 이메일/비밀번호 로그인, 이메일 확인, 세션 복구·갱신. 학번은 로그인 ID가 아닌 비공개 프로필 속성입니다.
- `gs_profiles`: 학교·단과대학·학과·학년·닉네임·아바타·활동 공개 설정. 가입 트리거로 생성합니다.
- `gs_challenges`: 서버에서 관리하는 챌린지와 앱 포인트 기준. `node scripts/seed_challenges.mjs`로 초기 SQL을 생성합니다.
- `gs_participations`: 참여·완료 시간과 CO₂ 계산 스냅샷. 사진은 비공개 `greenstep-evidence` 버킷에 저장합니다.
- `gs_points`: 서버에서 적립하는 원장. 참여 ID·퀴즈 날짜·보너스 종류별 유일 키로 중복 적립을 막습니다.
- `gs_invites`, `gs_friends`: 재발급 가능한 초대 코드와 상호 친구 관계. QR은 외부 이미지 서비스 없이 기기에서 생성합니다.
- `gs_quizzes`, `gs_quiz_answers`: 계정별 한국 시간 하루 한 문제와 답안. 정답·해설은 답안 제출 전 브라우저에 보내지 않습니다.

닉네임·학교·학과·앱 포인트·감축 합계는 로그인한 사용자의 랭킹에 표시됩니다. 친구 상세 활동은 기본 비공개이며 마이페이지에서 공개를 켜야 합니다. 이메일·학번·사진은 친구 조회에 포함되지 않습니다.

## 배포 순서

1. 같은 프로젝트에서 `202610160001_carbon_reference.sql`, `202610160002_accounts_friends.sql`, `202610160003_challenge_seed.sql` 순서로 실행합니다. 002는 일회성 migration이며 반복 실행용이 아닙니다.
2. `greenstep-chat` Edge Function을 현재 코드로 배포합니다. 기존 `GEMINI_API_KEY`, `GEMINI_MODEL`을 유지합니다. 함수의 서버 전용 `SUPABASE_SERVICE_ROLE_KEY`는 Supabase가 제공합니다. 브라우저 환경변수에 넣지 않습니다.
3. Supabase Authentication의 Site URL을 실제 운영 URL로, 허용 Redirect URL에 운영 URL 및 필요한 localhost 주소를 등록합니다. 이메일 확인 설정은 유지합니다.
4. Vercel에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`가 같은 프로젝트인지 확인하고 프런트엔드를 재배포합니다. 이 두 값은 공개 가능한 연결 정보이며 개인 데이터 접근은 RLS·RPC로 제한합니다.

## 동작과 제한

- 계정 정보는 로그인·새로고침·창 복귀 시 다시 읽습니다. 화면이 열린 동안 60초마다 갱신하며 친구/랭킹에는 새로고침 버튼도 있습니다.
- 브라우저의 예전 데모 계정·포인트·친구를 실제 데이터로 가져오지 않습니다. 사용자는 새 이메일 계정으로 가입해야 합니다.
- 가입 시 이메일 확인이 켜져 있으면 확인 전에는 앱에 로그인하지 않습니다. 학교·시민 구분은 자기 입력이며 재학·거주 사실을 검증하지 않습니다.
- 사진은 5MB 이하 JPEG/PNG/WebP. 사진 내용 자동 심사 기능은 없습니다. 완료 시 **앱 실천 포인트**를 지급하며 정부 지원금의 실제 지급을 보장하지 않습니다.
- 같은 인증 재시도는 같은 참여 ID를 사용합니다. 완료 후 새 참여는 별도 활동입니다.
- 포인트는 클라이언트 `updateProfile`로 변경할 수 없습니다. 퀴즈 정답 10P, 연속 3일 30P·7일 100P(각 계정 첫 달성), ISO 주 기준 5개 완료 50P를 서버가 계산합니다.
- 친구 상세 활동은 최근 완료 30건. 공유를 끄거나 친구를 해제하면 이후 조회가 차단됩니다.
- 관리자 화면의 챌린지 편집은 운영 DB를 변경하지 않습니다. 서버 챌린지 기준 변경은 권한 있는 운영자가 seed/migration으로 반영해야 합니다.
- 배지는 저장된 활동·포인트와 별도로 활동 기록에서 재계산합니다. 일일 연속 기록은 현재 연속 일수 기준입니다.

## 운영 점검 순서 (수동)

서로 다른 이메일 계정 두 개로 가입/이메일 확인 → 별도 브라우저에서 로그인 → 사진 인증 후 새로고침/다른 기기에서 기록 확인 → QR 링크로 상대 프로필 확인·친구 추가 → 활동 공개 켜기/끄기 → 친구 랭킹 확인 → 로그아웃 후 다른 계정의 개인 정보가 남지 않는지 확인합니다.
